# Personal Portfolio

A responsive personal portfolio website built using **HTML5, CSS3, and Bootstrap 5** to showcase my skills, education, and projects as an aspiring Full-Stack Developer.

## Features
- Responsive design for desktop and mobile devices
- Modern gradient background and smooth scrolling
- Animated hero section with a CSS typewriter effect
- Interactive Skills and Education sections using Bootstrap Collapse
- GitHub and LinkedIn social links

## Technologies Used
- **HTML5** – Website structure
- **CSS3** – Styling, animations, and layout
- **Bootstrap 5** – Responsive components and grid system

## Purpose
This project was created to strengthen my front-end development skills and serve as a personal portfolio to showcase my progress, technical abilities, and future projects.
